# 澳门六合彩 · 多层罗盘 — 使用说明（README）

## 一、这是什么

一个**本地自包含**的 HTML 应用：以"同心圆多层罗盘"的形式，把 49 个号码在 **生肖 / 49 数字 / 平均遗漏 / 当前遗漏 / 最大遗漏 / 总出现次数 / 近 100 期出现次数 / 下期统计参考概率** 等维度上的历史表现全部可视化，并额外保留波色、头数、尾数、节日等维度供悬停查看与推荐理由参考。

双击打开即可使用，**无需联网、无需安装、不依赖任何服务器**。所有历史数据与计算逻辑都打包在单个 HTML 文件内。

> 本应用为数据分析与娱乐参考工具，任何统计结论均为**描述性参考**，不构成预测保证，请理性对待。

## 三、快速开始

1. 双击打开 `多层罗盘应用.html`；
2. 鼠标**悬停**罗盘任意扇区查看该号码全部维度详情；悬停/点击各层**层名标注**（L1-L9 徽标）可查看该层名称与含义；
3. **按住并拖拽**某一层（生肖层/号码层等任意数据层）的任意扇区，可让该层**独立旋转**，其它层保持不动；点「重置旋转/复位」恢复初始对齐；
4. 在右上角输入框输入当天开奖特码（01-49），点击**「更新并入数据」**；
5. 页面自动重算遗漏/频次/推荐，并展示**下期参考号码 Top 10**（含描述性理由）；
6. 点「重置手动记录」可清除手动并入的数据，恢复原始 2356 期基线。

## 四、罗盘九层结构（由内到外）

| 层 | 名称 | 含义与着色 |
|---|---|---|
| L1 | 中心信息盘 | 总期数、最新期号、最新特码与日期（中心核心） |
| L2 | 生肖层 | **12 格**，每格一个生肖，标注生肖名 + 对应号码（当年生肖 5 个、其余 4 个）；12 色按生肖区分 |
| L3 | 号码层 | **49 格**，每格标注号码本体 01-49 |
| L4 | 平均遗漏层 | **49 格**，每格标注该号码历史平均遗漏期数（保留 1 位小数；绿=小 → 红=大） |
| L5 | 当前遗漏层 | **49 格**，每格标注截至最新一期的当前遗漏期数（绿=小 → 红=大） |
| L6 | 最大遗漏层 | **49 格**，每格标注历史最大遗漏期数（蓝=小 → 紫=大） |
| L7 | 总出现次数层 | **49 格**，每格标注全量历史出现次数（蓝=少 → 红=多） |
| L8 | 近100期层 | **49 格**，每格标注最近 100 期出现次数（橙=少 → 红=多） |
| L9 | 下期统计参考概率层 | **49 格**，每格标注统计参考概率百分比（如 2.7%；金=低 → 红=高），为**统计参考概率，非真实开奖概率** |

中心盘显示：总期数、最新期号、最新特码与日期。扇区最外圈有号码刻度便于定位。悬停任一扇区可查看该号码**全部维度详情**（出现次数、各遗漏、近 100 期/近 30 期次数、下期统计参考概率、波色、头尾数、节日出现次数、最近出现等）。

**每层标注**：每一层在右上角环带位置都有一个固定的层名徽标（`L1 中心信息` / `L2 生肖` / `L3 号码` / `L4 平均遗漏` / `L5 当前遗漏` / `L6 最大遗漏` / `L7 总次数` / `L8 近100期` / `L9 参考概率`）。徽标不随该层旋转，始终可见；**悬停或点击徽标**会弹出该层的名称、含义说明与当前旋转角度。右侧「图层说明」表同步展示每层的层号、层名与含义。

**格标注**：L2 生肖层共 **12 格**，每格跨约 4 个号码格的角度范围，环内标注生肖名（简体：鼠/牛/虎/兔/龙/蛇/马/羊/猴/鸡/狗/猪），环外标注该生肖对应的 4~5 个号码（如「07 19 31 43」），生肖格间以加粗分界线隔开；L3-L9 数据层各 **49 格**，每格环内标注对应数值（L3 号码本体、L4 平均遗漏保留 1 位小数、L5 当前遗漏、L6 最大遗漏、L7 总次数、L8 近100期次数、L9 参考概率百分比），文字带描边保证小字号清晰，字体大小随层宽度自动适配。悬停生肖格弹出该生肖对应号码的频次/遗漏汇总；悬停号码格仍弹出单号码全维度详情。

## 五、每层独立旋转

- 罗盘数据层（L2-L9）各自是独立的旋转分组；**按住并拖拽任意一层中的任意扇区**，仅该层绕中心旋转，其它层保持不动（L2 为 12 格整体旋转，L3-L9 为各自 49 格整体旋转）；
- 旋转过程平滑（带 0.22s 过渡动画），各层格内标注（生肖名/号码/数值文字）跟随该层一起转动；分隔参考线与外圈刻度固定不动；
- 旋转**纯属视觉对齐调整，不影响任何统计与推荐计算**；更新数据、重置记录后各层旋转角度保持不变；
- 罗盘左上角状态栏实时显示各层当前旋转角度（L2-L9 各 0-359°）；
- 点**「重置旋转/复位」**按钮，将全部数据层恢复到初始对齐（0°）；悬停扇区时工具提示中也会显示该层当前旋转角度。

## 六、生肖-号码映射

**规则**：每年农历新年（春节）轮换一次映射。当年生肖固定对应号码 **01**，随后按生肖**倒序**循环排列（鼠→牛→虎→兔→龍→蛇→馬→羊→猴→雞→狗→豬 的逆序）。

例：**馬年（2026 农历）** 01=馬、02=蛇、03=龍、04=兔、05=虎、06=牛、07=鼠、08=豬、09=狗、10=雞、11=猴、12=羊、13=馬…

因 49 = 12×4 + 1，每个生肖对应 **4 个号码**，其中当年生肖多占 1 个（对应 01/13/25/37/49 共 5 个）。

页面内「图层说明与映射表」中自动展示**当前农历年完整 49 码生肖表**；历史期号均按其开奖日所属农历年单独计算，与原始数据 `zodiac` 字段一致。

## 八、如何更新当天特码

1. 输入 1-49 之间的整数（两位数可省略前导 0，如 `7` 或 `07`）；
2. 点击**「更新并入数据」**，该期会以当天日期并入统计（期号标记为「手XXXX」）；
3. 更新后：**9 层全部重算**（平均遗漏、当前遗漏、最大遗漏、总出现次数、近 100 期次数、下期统计参考概率、生肖映射如需），中心盘、全局统计、近 30 期明细、推荐列表同步刷新；页面即时给出反馈，如「已并入第 手XXXX 期，数据共 N 期；9 层全部重算…」；
4. 手动并入的记录保存在浏览器 **localStorage**（本机、本浏览器），关闭页面仍在；点「重置手动记录」即可清除；
5. 提示信息会显示当天是否为内置节日（公历/农历）。手动日期若不在内置节日表内，仅显示无节日标注。

## 九、数据说明

- **数据源**：`compass_data_full.json`，共 **2356 期**（2020-05-18 至 2026-10-31）；
- **字段口径**：`openCode` 为 7 个开奖码，**末位为特码**；`wave` / `zodiac` 均指特码；
- **节日标注**：内置近 5 年公历节日与农历节日（春节、元宵、清明、端午、中秋、重阳等主要节日），共 **165 个开奖日**含节日标注；
- **期号口径**：以数据文件 `expect` 为准，历史各渠道期号标签可能口径不同，号码一致即可；
- **统计口径**：占比=次数/期数；遗漏=相邻出现之间的间隔期数；z 值=(频次-期望频次)/标准差；**下期统计参考概率**=频率 0.25 + z 值 0.30 + 当前遗漏 0.25 + 平均遗漏 0.20（各维度归一化后加权，再对 49 码归一化为百分数）。该概率为**统计参考概率，非真实开奖概率**（真实开奖概率恒为 1/49≈2.04%），详见《推荐算法说明.md》。

## 十、常见问题

- **为什么推荐会变化**：每次并入新特码后，当前遗漏、近 100 期/总出现次数、平均/最大遗漏、生肖映射等全部重算，下期统计参考概率随之更新，推荐列表随之变化。
- **数据会不会上传**：不会。纯本地运行，手动记录仅存于本机浏览器。
- **换浏览器/换电脑**：手动并入记录不共享；重新并入即可。
- **如何查看某号码全部历史**：悬停该号码扇区，工具提示内含出现次数、各遗漏、最近出现、最近 10 次明细。

## 十一、手机版使用说明（手机版多层罗盘.html）

**文件**：`手机版多层罗盘.html`（自包含单文件，数据与桌面版一致，含 2356 期全量数据与全部统计逻辑）。

### 1. 如何在手机上打开
- **本机浏览器直接打开**：双击 `手机版多层罗盘.html`，用浏览器（Chrome / Edge / Firefox / Safari 等现代浏览器）打开即可，无需联网、无需安装任何依赖。
- **通过微信传输到手机**：
  1. 在电脑上把 `手机版多层罗盘.html` 文件发送到「文件传输助手」（或手机QQ/微信任意聊天窗口）；
  2. 在手机微信中点击该文件 → 选择「用其他应用打开」→ 选择手机浏览器（建议 Chrome / Safari，微信内置浏览器亦可但交互体验略受限）打开；
  3. 打开后即可正常使用全部功能。
- **手机浏览器打开本地文件注意**：部分浏览器需在文件管理器中定位到下载目录后点击打开；文件仅在本机浏览器内运行，不涉及任何上传。

### 2. 手机版交互差异（相对桌面版）
- **竖屏响应式**：单列布局，罗盘自适应屏幕宽度，字号与按钮尺寸已按触屏加大，深色主题，无横向滚动。
- **触控旋转**：单指按住某一层的扇区拖动即可**只旋转该层**，其余层不动；旋转仅影响视觉对齐，不影响数据与推荐计算。
- **缩放罗盘**：罗盘下方工具条提供「＋ / － / 1:1」按钮缩放；也支持**双指捏合**直接缩放（缩放范围 80% ~ 260%）。
- **点击查看详情（替代悬停）**：手机没有鼠标悬停，改为**点击**任意扇区或层名徽标，在屏幕底部弹出详情抽屉（号码次数、各遗漏、生肖号码、层说明等）；点击空白处或再次操作即可关闭。
- **大按钮输入更新**：输入框自动唤起**数字键盘**（`inputmode=numeric`），输入 01-49 后点大号「更新并入数据」按钮（或直接按键盘「完成/回车」），9 层全部重算并刷新下期参考 Top 10。
- **重置旋转 / 重置数据**：「重置旋转/复位」恢复各层初始角度；「重置手动记录」清除 localStorage 中手动并入的期数。
